# Recording checklist

## Environment

- [ ] Notifications and focus-stealing applications disabled.
- [ ] Browser at 1440×900 or equivalent 1080p output, zoom 100%.
- [ ] Cursor visible; no desktop/private tab exposure.
- [ ] Address bar visible with the canonical `.run.app` URL.
- [ ] Microphone level tested; narration intelligible.
- [ ] No terminal, API key, token, IAM detail or private account page visible.

## Preflight

- [ ] `/health` returns 200.
- [ ] Cloud Tasks queue is empty.
- [ ] Live UI loads anonymously over HTTPS.
- [ ] Reliability proof is ON.
- [ ] Create one new run at the beginning of the take.
- [ ] Final narration and pronunciation rehearsed.

## Live proof

- [ ] Maya → Liam → Sofia verified.
- [ ] Noah → Emma visibly waiting.
- [ ] Early wake visibly safe.
- [ ] EVT-004 is the last click.
- [ ] Autonomous resume visible.
- [ ] Controlled HTTP 503 disclosed before/when shown.
- [ ] Same Cloud Task retry and `NO_OP_VERIFIED` visible.
- [ ] Versions and custody unchanged on retry.
- [ ] `.run.app` proof visible.
- [ ] Continuous 1× take ≤3:45 target and never over 4:00.

## Review before upload

- [ ] Watch from beginning to end at 1×.
- [ ] Verify audio, cursor, labels and evidence remain legible.
- [ ] Verify no notification, credential, PII or misleading cut appears.
- [ ] Confirm English narration, or add reviewed English subtitles.
- [ ] Upload publicly only after explicit human approval.
