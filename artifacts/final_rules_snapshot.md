## Confirmed requirements

| Item | Current official requirement |
|---|---|
| Deadline | August 31, 2026 at 5:00 PM PDT (September 1 at 00:00 UTC; August 31 at 21:00 America/Sao_Paulo). |
| Required stack | Gemini 3.5 or newer, at least one eligible Google agent framework, and at least one Google Cloud infrastructure service. |
| Category | Select exactly one. ShiftChain fits **Taskmaster**. |
| Hosted application | URL is highly encouraged. The application shown must function as represented. |
| Repository | Public or private GitHub/GitLab/Bitbucket URL. A private repository must grant access to the two official judging accounts named in the Rules. |
| README | Step-by-step local spin-up or cloud deployment instructions. |
| Architecture | Clear architecture diagram showing Gemini, backend, data and frontend relationships. |
| Video | Publicly visible on YouTube or Vimeo; maximum four minutes; only the first four minutes may be evaluated. |
| Video content | Problem, value and application in action; visible proof that the backend runs on Google Cloud, including a `.run.app` URL as an accepted example. |
| Language | English, or English subtitles. |
| Proof of action | Judging guidance asks for a live, unedited execution showing observable action. ShiftChain's package therefore retains a continuous 1× take. |
| Editing before deadline | Drafts may be updated before the Submission Period ends. |
| Freeze after deadline | No Submission alterations after the Submission Period, except a narrow organizer-authorized correction for prohibited/infringing/private material. FAQ additionally says to leave video, repository and hosted app exactly as submitted until winners are announced. |
| Judging | Innovation & Operational Utility 40%; Architectural Discipline & Tech Stack 30%; Demo & Production Readiness 30%. |

## Optional contributions and prizes

- Public build article/podcast/video, explicitly stating it was created for entering this hackathon: up to +0.2.
- Public social post: up to +0.2. The Rules specify **`#AllThingsAgenticHackathon`**. The FAQ renders the wording inconsistently in one place; the Rules' no-space hashtag is used in drafts.
- Additional eligible Google AI models: +0.2 each, maximum +0.6. ShiftChain will not add a model for bonus points.
- Relevant prize positioning visible on the official contest page: Individual/Hobbyist and Best Architectural Design. Startup Excellence requires an incorporated organization and corporate email and is not assumed.
