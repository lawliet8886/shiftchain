ShiftChain — All Things Agentic Hackathon Demo

## Description

ShiftChain is an autonomous temporal reconciliation agent that turns human responsibility handoffs into safe, verified state changes—even when confirmation arrives late or infrastructure retries the same task.

Built with Gemini 3.7 Flash, Google ADK, Google Cloud Run, Cloud Firestore, Cloud Tasks, Secret Manager, FastAPI and Python.

Live application: https://shiftchain-demo-7skxzw642a-uc.a.run.app

Source and architecture: https://github.com/lawliet8886/shiftchain

Judge Mode intentionally simulates one lost acknowledgement after the verified business effect. The native Cloud Tasks retry performs read-before-repeat and produces `NO_OP_VERIFIED` without a duplicate mutation.

All organization, worker, shift and message data shown are synthetic. This project and video were created for the purpose of entering the All Things Agentic Hackathon.
